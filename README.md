# Benny Lebelo Portfolio

Premium black-and-white Next.js portfolio scaffold with:
- Multi-page architecture (Home, About, Experience, Projects, Education, Skills, Contact, Chat)
- Structured TypeScript data models
- Recruiter-focused content sections
- API route for profile-aware AI chat responses
- Dark-first visual style ready for Ant Design and Three.js enhancement

## Run locally

```bash
npm install
npm run dev
```

## Environment

Create `.env.local` and set:

```bash
OPENAI_API_KEY=your_key_here
```
