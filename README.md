# Benny Lebelo Portfolio

Premium black-and-white portfolio built with Next.js, TypeScript, Ant Design, Three.js, and an AI chatbot route.

## Quick start

```bash
npm install
npm run dev
```

## Environment variables

Create `.env.local`:

```bash
OPENAI_API_KEY=your_key
OPENAI_MODEL=gpt-4.1-mini
```

If `OPENAI_API_KEY` is missing, the chat UI remains available and the API route responds with a configuration message.
